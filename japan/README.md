# 日本旅行攻略

日本总览：https://boldline.github.io/traveling/japan/

## 目的地

- [福冈 · 九州慢旅](./fukuoka/README.md)：福冈、由布院与别府 7 天 6 晚亲子旅行。线上攻略：https://boldline.github.io/traveling/japan/fukuoka/

每个城市使用独立目录。新增目的地时创建对应城市目录与 `app/japan/<城市>/` 路由，在 `destinations.ts` 增加卡片数据，并更新静态导出检查列表。该目的地的 `public/` 图片会自动同步到网站对应路径。开发和部署命令在仓库根目录运行，详见根目录 README。
