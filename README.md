# 九州慢旅

2026-09-25 至 2026-10-01 福冈、由布院与别府亲子旅行手册。中文优先、手机可读，汇总每日安排、住宿、美食、跨城交通、票价、预约提示与紧急电话。

内容来源为用户提供的行程原稿及 2026-09-06 核查的官方信息。`lib/trip.ts` 集中保存日期、地点、餐厅、酒店与来源。未接入实时票务或预订系统；没有完成任何旅行预订。

使用 npm install 安装，npm run dev 本地运行，npm run build 静态构建。生产输出在 dist/client。根目录之外的现有项目保持独立。
